# 🚀 Features

## Guest Features

✅ RSVP for the event with meal preferences  
✅ Secure authentication with unique tokens  

## Admin Features

✅ Secure login with JWT authentication  
✅ Manage guest lists and RSVPs  
✅ View event statistics (attendees, meal preferences, etc.)  

# ⚙️ Tech Stack

- Frontend: React, React Router, Axios, Context API
- Backend: Node.js, Express, JWT authentication, Multer (for image uploads)
- Database: MongoDB with Mongoose


# 🔐 Authentication & Security

- Admins log in securely using JWT.
- Protected routes ensure only authorized users can access admin features.
- Passwords are encrypted with bcrypt.

# 🔧 Installation & Setup

## 1️⃣ Clone the Repository
``git clone [https://github.com/samw1se97/rsvp-app.git]``


``cd rsvp-app``  

## 2️⃣ Install Dependencies
``# Install server dependenciest``


``cd server``


``npm install``  

``# Install client dependenciest``


``cd ../client``


``npm install``



## 3️⃣ Start the Application
# Run the backend server  
``cd server``


``npm run start:dev``



# Run the frontend React app
``cd ../client``


``npm run dev``
